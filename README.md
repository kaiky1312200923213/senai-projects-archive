**Autor:** Kaiky Yoshio Ono Marins  
**Categoria:** Python · Agentes de IA · Dados  
**Status:** Caderno de estudos e experimentos

## Visão geral

Coleção de exercícios e experimentos desenvolvidos durante os estudos. O material reúne exemplos de agentes conversacionais, instruções de comportamento, memória com SQLite, extração de conteúdo da web e consultas a dados financeiros.

## Temas presentes no material

- Agentes com Agno e modelos compatíveis com a API da OpenAI.
- Instruções e definição de personas.
- Persistência de conversas com SQLite.
- Extração de texto com Requests e BeautifulSoup.
- Consulta e análise de dados com Pandas, SQL e yfinance.
- Exemplos de chatbots de boas-vindas, FAQ e culinária.

## Tecnologias identificadas

- Python
- Agno
- NVIDIA NIM / API compatível
- SQLite
- Requests e BeautifulSoup
- Pandas e yfinance
